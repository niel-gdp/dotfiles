# nvim-config

Daniel Adamlu's personal Neovim config, based on [LazyVim](https://github.com/LazyVim/LazyVim), tuned for DevOps/SRE work (Terraform, Kubernetes/Helm, Docker, Ansible, YAML/JSON schemas, Bash).

Refer to the [LazyVim documentation](https://lazyvim.github.io/installation) for general setup and keymaps.
